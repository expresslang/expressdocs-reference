=== Terms and definitions

==== agreement of common understanding

result of discussions between the partners of product data exchange or sharing that ensures that all of
them have the same understanding of the transferred or shared information

NOTE: The agreement may be formalized in a document.


==== annotated EXPRESS schema

EXPRESS schema for which a natural language definition is given with each CONSTANT, TYPE, ENTITY, RULE, FUNCTION or PROCEDURE construct

[example]
Clause 5.2 of an application protocol contains an annotated EXPRESS schema.

==== chain

path in which all nodes and links are distinct


==== class of products

set of all products satisfying a type of product; the elements of the set are referred to as members of the class

NOTE: A class need not have any members.

NOTE: The definition of the type will determine whether the size of the set varies with time.

NOTE: This definition was adapted from ISO/IEC 10746-2:1996 [1].



==== contract

a binding agreement


==== degree of a node

number of direct connections to other nodes


==== management information

Information required for proper control and handling of a specific product or item.

NOTE: Management data may include information related to scheduling, roles, certifications, approvals, effectivity and life-cycle stages.

[example]
An inspection certification indicates that the product has passed inspection and is ready to move to the next step
in the product life cycle.


==== path

a sequence of nodes such that from each of itse nodes thre is an edge to the next node in the sequence; it has two terminal nodes (nodes that have degree 1), while all others (if any) have degree 2

NOTE: The first and last nodes in the path are different. No nodes are referenced more than once by a link.


==== real object

object that exists or did exist in the real world and that can or could be uniquely identified

NOTE: An individual object may result from a manufacturing process or it may exist independently of any human process.

[example]
The Moon is an individual object that is not the result of a human process.


==== type_of_product

predicate characterizing a collection of products; a product is of the type, or satisfies the type, if the
predicate holds for that product

[example]
This definition was adapted from ISO/IEC 10746-2:1996 [1].


==== version

a unique revision of an item
