ENTITY action_resource;
  name : label;
  description : OPTIONAL text;
  usage : SET [1:?] OF supported_item;
  kind : action_resource_type;
END_ENTITY;


(*"action_resource"
An *action_resource* is a thing that is identified as being needed to carry out an action.
*)


(*"action_resource.description"
the
express_ref:[support_resource_schema.text]
that characterizes the *action_resource*.
The value of the attribute need not be specified.
*)


(*"action_resource.kind"
the
express_ref:[action_schema.action_resource_type]
that specifies the sort of *action_resource* that is being used.
*)


(*"action_resource.name"
the
express_ref:[support_resource_schema.label]
by which the *action_resource* is known.
*)


(*"action_resource.usage"
a set of
express_ref:[action_schema.supported_item]s
for which the *action_resource* is used.
*)
