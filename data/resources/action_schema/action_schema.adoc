== General

The subject of the *action_schema* is the description of actions,
the reasons for these actions, and the status of these actions.

EXAMPLE: Reasons for action include evolving user requirements,
manufacturing problems and difficulties that arise when a product
is in use.

== Fundamental concepts and assumptions

Action information can be attached to any aspect of product data.
