ENTITY action_resource_relationship;
  name : label;
  description : OPTIONAL text;
  relating_resource : action_resource;
  related_resource : action_resource;
END_ENTITY;


(*"action_resource_relationship"
An *action_resource_relationship* is a relationship between two instances of the entity data type
express_ref:[action_schema.action_resource]
and provides an identification and description of this relationship.

NOTE: The role of *action_resource_relationship* can be defined in the annotated EXPRESS schemas that use
or specialize this entity, or by default, in an agreement of common understanding between the partners sharing this information.


NOTE: This entity, together with the
express_ref:[action_schema.action_resource]
entity, is based on the relationship template that is described in annex E.3.

*)


(*"action_resource_relationship.description"
the
express_ref:[support_resource_schema.text]
that characterizes the *action_resource_relationship*.
The value of the attribute need not be specified.
*)


(*"action_resource_relationship.name"
the
express_ref:[support_resource_schema.label]
by which the *action_resource_relationship* is known.
*)


(*"action_resource_relationship.related_resource"

the other instance of
express_ref:[action_schema.action_resource]
that is a part of the relationship.
If one element of the relationship is dependent upon the other this attribute shall be the dependent one.


NOTE: The meaning of this attribute can be defined in the annotated EXPRESS schemas that use or specialize
this entity, or in an agreement of common understanding between the partners sharing this information.

*)


(*"action_resource_relationship.relating_resource"

one of the instances of
express_ref:[action_schema.action_resource]
that is a part of the relationship.


NOTE: The meaning of this attribute can be defined in the annotated EXPRESS schemas that use or specialize
this entity, or in an agreement of common understanding between the partners sharing this information.

*)
